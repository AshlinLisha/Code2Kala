# Code2Kala
KalaSetu is an AI-powered digital showcase giving local artisans direct market access. Features AI description enhancement, fair price prediction, and zero-commission direct buyer connection via WhatsApp/Call.

🌟 Main Features:
📝 AI Description Generator: Turns simple words into nice product stories.

💰 AI Price Predictor: Helps artisans set a fair price for their products.

📞 Direct Contact: Buyers can contact artisans directly through WhatsApp or phone calls.

🛍️ Simple Catalog: Easy website for buyers to search and discover local crafts.
